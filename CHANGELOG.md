# Changelog

## [0.1.0] - 2026-06-03

### Added
- Core inference engine with ROCm support
- FP16 and INT8 quantization
- GPU memory management utilities
- Benchmark suite with CSV export
- CLI interface for inference and benchmarking
- Unit test suite
- GitHub Actions CI (lint, test, build)

### Supported Models
- BERT (base, large, distilbert)
- GPT-2 variants
- Any HuggingFace Transformer model
